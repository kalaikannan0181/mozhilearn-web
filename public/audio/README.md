# Mundari audio repository

This directory is reserved for verified, real Mundari audio assets that are later uploaded and referenced by the web app.

Rules:
- Do not add fake or generated audio.
- Do not claim Mundari speech support unless the audio has been validated by a human reviewer.
- Store files in a clear structure such as `public/audio/mundari/vocabulary/`, `public/audio/mundari/classroom/`, or `public/audio/mundari/lessons/`.
- Reference audio paths from the app with a `/audio/...` URL.
- Keep provenance and source metadata alongside the content that uses the asset.

This repository intentionally does not ship fake placeholders or fabricated Mundari audio.
